Cuaderno de gastos

App web sencilla para registrar gastos e ingresos, ver el dinero disponible y exportar un PDF de cada mes.

Características
Registro en 3 pasos: Gasto/Ingreso → tipo y nota → importe
Fecha automática
Dinero disponible y gastos del mes en la pantalla principal
Balance e historial por mes
Exportar PDF mensual
Modo oscuro automático
Los datos se guardan solo en tu navegador (localStorage); no se envían a ningún servidor
